## 1. 서비스 개요

### 1-1. 배경

아이를 돌보다보면 잠깐 쉬기도 어렵습니다. 자폐·발달장애 아동을 키우는 경우
특히 그렇습니다. 바쁘게 지내다보니 정작 가족이 함께 마음을 살피고 실천할
여유를 내기가 어려웠습니다. 그래서 긴 상담이나 거창한 계획 대신, "지금 그
마음이 그럴 만하다"는 한마디와 5분 안에 해볼 수 있는 작은 실천 하나를 매일
받아갈 수 있는 서비스를 기획했습니다.

### 1-2. 목적

육아로 지친 부모가 하루 3분 안에 오늘의 감정을 기록하고, AI로부터 공감과
아주 작은 실천 제안을 받아가도록 돕는다. 진단이나 치료를 대체하지 않고,
매일 반복 가능한 짧은 자기 돌봄 루틴을 제공하는 것이 목적이다.

### 1-3. 타겟 사용자

- 1차 타겟: 자폐·발달장애 아동을 키우는 부모
- 2차 타겟: 육아로 지쳐 짧은 쉼과 인정이 필요한 보호자 전반

실명, 생년월일, 진단명, 연락처, 사진 등 민감정보를 요구하지 않아 처음
접근하는 사람도 심리적 장벽 없이 사용할 수 있도록 설계했다. 회원가입 절차도
두지 않았다.

### 1-4. 이름의 유래

첫째 아이의 이름 시온(始溫) — 처음 시, 따뜻할 온 — 에서 따왔다. 따뜻함이
하루씩 쌓여 숲이 된다는 뜻으로 '따숲'이라 이름 붙였다. 지금은 한 사람이
나무 한 그루를 심는 수준이지만, 다른 부모들에게도 확장되어 숲이 될 수 있게
여는 문이 되기를 바라는 마음을 담았다.

## 2. 페이지 / 섹션 구성

| 섹션 | 역할 | 비고 |
| --- | --- | --- |
| 랜딩(Landing) | 서비스 소개, "회원가입 없음·서버 저장 없음" 고지 | 첫 방문자가 가장 먼저 보는 화면 |
| 온보딩(Onboarding) | 처음 방문자를 위한 간단한 사용 안내 | |
| 오늘의 체크 | 오늘의 기분 등 상태를 남기는 화면 | |
| 대시보드 | 기록 누적에 따른 레벨·성장(새싹) 그래픽, 오늘의 미션 3개 | "작게 시작해도 괜찮아요. 이미 자라고 있어요" 문구로 죄책감 완화 |
| 설정 | 개인화 옵션 | |
| 마음 쉼터(AI) | 기분 선택 + 한 줄 메모 입력 → AI 공감 카드 출력 | 이 서비스의 핵심 AI 기능 |

메뉴 이동은 상단 `header-nav`로 각 섹션(`view-*`)을 전환하는 방식이다.

```
                        상단 nav (header-nav)
                 ┌────────┬─────────┬─────────┬────────┐
                 │        │         │         │        │
                 ▼        ▼         ▼         ▼        ▼
            [랜딩] → [온보딩] → [오늘의 체크] → [대시보드] ⇄ [설정]
                                                    │
                                                    ▼
                                              [마음 쉼터 (AI)]
                                          기분 선택 + 한 줄 메모
                                          → 공감 카드 출력
```

처음 방문자는 랜딩 → 온보딩 → 오늘의 체크 순으로 자연스럽게 이어지고,
이후에는 대시보드를 허브 삼아 설정과 마음 쉼터로 자유롭게 이동한다.

## 3. 핵심 기능

1. **오늘의 체크** — 오늘의 기분 등 상태를 짧게 기록한다.
2. **대시보드** — 기록이 쌓일수록 레벨과 새싹 그래픽이 성장하며 꾸준함을
   시각적으로 보여준다. 오늘의 미션 3개를 함께 제시해 하루 안에 해볼 작은
   행동을 안내한다.
3. **마음 쉼터(AI)** — 기분 선택과 한 줄 메모를 입력하면, AI가 공감과 오늘의
   실천 제안을 담은 카드를 만들어 준다. 이 과제의 핵심 AI 기능이다.

데이터는 서버에 저장하지 않고 브라우저의 localStorage에만 남긴다. 마음
기록처럼 민감할 수 있는 내용을 서버에 두지 않는 편이 사용자에게 더
안전하다고 판단했기 때문이다.

## 4. AI 기능 설계

### 4-1. 입력

| 필드 | 설명 | 제약 |
| --- | --- | --- |
| `mood` | 오늘의 기분 | 선택형 |
| `note` | 한 줄 메모 | 필수, 프런트 300자 제한(글자 수 카운터 표시), 서버는 500자까지 허용 |
| `mission` | 진행 중인 미션 | 선택 |

### 4-2. 출력

AI 응답은 아래 4개 항목으로 형태를 고정한다. 매번 다른 형태의 글이 오면
사용자가 어디에 집중해야 할지 헷갈리기 때문이다.

1. 키워드 — 오늘의 기분을 담은 한글 단어 하나
2. 제목
3. 공감 메시지 — 두 문장 이내
4. 오늘의 한 걸음 — 5분 안에 해볼 수 있는 아주 작은 실천 제안 한 문장

AI에게는 "판단하거나 훈계하지 말고 먼저 공감할 것", "존댓말을 쓰되 딱딱하지
않을 것", "의학적 진단·치료 조언을 하지 않을 것"을 프롬프트 규칙으로
명시한다.

### 4-3. 실패 처리 기준

| 상황 | HTTP 상태 | 코드 | 사용자 안내 |
| --- | --- | --- | --- |
| 빈 입력(`note` 없음) | 400 | `EMPTY_INPUT` | "오늘의 기록을 한 줄이라도 남겨 주세요." |
| 요청 형식 오류 | 400 | `BAD_JSON` | "요청 형식이 올바르지 않아요." |
| 서버 키 미설정 | 500 | `NO_API_KEY` | "서버 설정이 완료되지 않았어요." |
| 요청 폭주 | 429 | `RATE_LIMIT` | "요청이 너무 많아요. 1분 뒤에 다시 시도해 주세요." |
| 인증 오류 | 502 | `AUTH_ERROR` | "AI 연결에 문제가 생겼어요. 관리자에게 문의해 주세요." |
| 그 외 업스트림 오류 | 502 | `UPSTREAM_ERROR` | "AI 응답을 받지 못했어요. 잠시 후 다시 시도해 주세요." |
| 응답 지연 | 504 | `TIMEOUT` | "숲이 잠시 조용하네요. 응답이 늦어지고 있어요." |
| 네트워크 오류 | 502 | `NETWORK_ERROR` | "네트워크 연결이 불안정해요. 잠시 후 다시 시도해 주세요." |
| AI가 JSON 형식을 어김 | 200 | (파싱 실패 대체) | 기본 문구("오늘의 쉼" / "숨을 세 번 천천히 쉬어 보세요.")로 대체해 화면이 비지 않게 함 |

분기 흐름은 다음과 같다.

```
 POST /api/generate
        │
        ▼
 GEMINI_API_KEY 있음? ──아니오──▶ 500 NO_API_KEY
        │ 예
        ▼
 요청 JSON 파싱 성공? ──아니오──▶ 400 BAD_JSON
        │ 예
        ▼
 note 비어있음? ──예──▶ 400 EMPTY_INPUT
        │ 아니오
        ▼
 Gemini API 호출
        │
        ├─ 타임아웃 ─────────────▶ 504 TIMEOUT
        ├─ 네트워크 오류 ─────────▶ 502 NETWORK_ERROR
        ├─ 429 ──────────────────▶ 429 RATE_LIMIT
        ├─ 401 / 403 ─────────────▶ 502 AUTH_ERROR
        ├─ 그 외 4xx/5xx ─────────▶ 502 UPSTREAM_ERROR
        │
        ▼ 200 OK
 응답 텍스트 추출 (thought 조각 제외)
        │
        ▼
 텍스트 있음? ──아니오──▶ 502 EMPTY_RESULT
        │ 예
        ▼
 JSON으로 파싱 가능? ──아니오──▶ 기본 문구로 대체 (화면은 비지 않음)
        │ 예
        ▼
 200 { ok:true, data:{ title, message, action, keyword } }
```

## 5. 기술 스택 요약

- 프런트엔드: HTML / CSS / JavaScript (프레임워크 미사용)
- 백엔드: Vercel Serverless Functions (Python 3.14, `api/generate.py`)
- AI: Google Gemini API (`gemini-flash-latest`)
- 저장소: 브라우저 localStorage (서버 저장 없음)

세부 개발 과정, 디버깅 기록, 과제요건 충족 근거는 저장소 루트의
[`report.md`](../report.md)에 정리되어 있다.
