# AI 코딩 도구 사용 과정 증빙

과제요건 "AI 코딩 도구 사용 과정(대화 로그/스크린샷)"에 대한 증빙 자료입니다.

## 진행 단계

### 1단계 — 초기 기획 (GenSpark)

프로젝트 초반에는 GenSpark AI와 대화하며 방향을 잡았습니다. 이때는 지금의
따숲(오늘의 기분 체크 + AI 공감 카드)보다 훨씬 큰 범위였습니다 — VB-MAPP/QABF
같은 ABA 진단 자료를 활용한 "홈 ABA 코치"(HomeABA Coach)라는 이름의, 진단→
AI 처방→주별 기록→행동기능 분석까지 갖춘 부모 코칭 서비스를 구상했습니다.
이 단계의 대화 스크린샷을 아래 `screenshots/`에 보관합니다.

- 서비스 컨셉, 페이지 6개 구성, AI 기능 3종(`/api/prescribe`,
  `/api/behavior`, `/api/review`) 설계
- `home-aba-coach/` 폴더 구조와 `api/prescribe.py` 등 엔드포인트 초안

### 2단계 — 범위 축소 및 심화 (실제 구현)

이후 과제 범위와 일정에 맞춰 훨씬 단순한 형태로 좁혀 실제로 구현했습니다.
지금 배포되어 있는 따숲(ddasoop)은 1단계의 복잡한 다중 엔드포인트 구조 대신
"오늘의 기분 + 한 줄 메모 → AI 공감 카드" 단일 기능(`api/generate.py`)으로
심화·재설계된 결과물입니다. 실제 코드 작성과 디버깅(모델 이름 404, 응답에
섞인 추론 흔적, 타임아웃 등)은 이 단계에서 이루어졌으며, 그 과정은
[`report.md`](../../report.md) 5-6절에 상세히 기록되어 있습니다.

**참고**: 이 2단계의 AI 도구 대화 로그/스크린샷은 가족 여행 중 이동 환경에서
작업하며 별도로 저장해두지 못해, 이번 제출에는 포함하지 못했습니다. 1단계
초기 기획 스크린샷으로 AI 활용 과정의 일부를 증빙합니다.
